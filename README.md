# Python Foundations Project Showcase

I spent 3 intensive days transitioning from isolated problem-solving puzzles to full application architecture. Here are the 4 stages I completed:

### 🚀 Stage 1: Text Utilities (Travel Booking Agent)
* Focus: Input cleaning, string manipulation, and initial branching flow.

### 🔄 Stage 2: State-Driven Continuous Loops (Virtual ATM)
* Focus: Keeping applications alive via continuous loops, state modifications (`balance`), and breaking mechanisms.

### 📋 Stage 3: Dynamic Data Collections (Campus Course Tracker)
* Focus: Memory management over time utilizing Python Lists to add and view dynamic datasets.

### 🗃️ Stage 4: Intermediate Engines (Student Grade Ledger)
* Focus: Structured key-value mapping utilizing Python Dictionaries to link specific grades to course records.
